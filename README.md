# Конспекты 
Тут должны быть конспекты с уника
Конспекты в основном основаны на информации с лекций в моем понимании, поэтому могут быть некоторые ошибки (возможно, в лекции, возможно, мои).

Написано в формате обсидиана, нет поддержки остальных приложений. Все плагины предустановлены в хранилище в папке `.obsidian`. Поэтому ничего дополнительно устанавливать не требуется, но это не гарантирует, что другие установки останутся после обновлений.
