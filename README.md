# Конспекты 
Тут должны быть конспекты с уника
Конспекты в основном основаны на информации с лекций в моем понимании, поэтому могут быть некоторые ошибки (возможно, в лекции, возможно, мои).

Лекции стараюсь делать все, но практики не всегда (скорее всего практик и не будет).

Иногда использую материал из чужих конспектов/презентаций лекций (и все еще стараюсь передать его по-своему), поэтому благодарю всех за помощь.

Написано в формате обсидиана, нет поддержки остальных приложений, даже если через них это все еще работает.

# ==🟠Важное изменение==

Плагины более **не предоставляются** в папке `.obsidian`, т.к. сама папка удалена, поэтому при ошибках в связи со старой версией данных, требуется локально пересоздать хранилище obsidian и установить необходимые плагины:
- [Obsidian git](obsidian://show-plugin?id=obsidian-git)
- [Excalidraw](obsidian://show-plugin?id=obsidian-excalidraw-plugin)
- `Obsidian functionplot` *в данный момент по каким-то причинам не доступен, но пока не использовался*


Такой переход связан с тем, что в папке `.obsidian` хранилось большое количество информации, которая конфликтовала при обновлении.
