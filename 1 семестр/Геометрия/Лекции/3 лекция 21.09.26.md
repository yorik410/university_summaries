# §2 Аффинное пространство

$(A, V, A\times A \to V)$ — аффинное пространство с ассоциированным касательным векторным пространством $V$
$A$ — точки
$X \in A$ — точка 
$(X, Y) \mapsto \overline{ XY } ~~ (=Y-X)$

если выполняются следующие аксиомы:
1) $\forall X \in A,~ v \in V~~\exists!Y \in A ~ | ~\overline{ XY } = v$
2) $\forall X, Y, Z \in A ~~ \overline{ XY } + \overline{ YZ } = \overline{ XZ }$

### Базовые следствия аксиом
1) $\forall x \in A ~~ \overline{ XX } = \mathbb{0} ~~ \Leftrightarrow~~ \forall v \in V ~~ v + \overline{ XX } = v$
	$\forall v \in V ~~ \exists! Y \in A ~ | ~\overline{ XY } = v \Rightarrow \overline{ XX } + v = \overline{ XX } + \overline{ XY } = \overline{ XY }=v$
2) $-\overline{ XY } = \overline{ YX }$
	$\overline{ XY } + \overline{ YX } = \overline{ XX } = \mathbb{0} ~~\Rightarrow~ v + \overline{ YX } = \mathbb{0} ~~ \Rightarrow ~\overline{ YX }=-v=-\overline{ XY }$

$E^n ~~~ n \in \{ 0, \dots 3 \}$
$[XY\rangle := (X, [XY])$ — направленный отрезок с началом в т.$X$ и концом в т.$Y$

$M:=\{ [XY\rangle ~ | ~ X, Y \in E^n\}$

$[XY\rangle \sim [WZ\rangle \overset {\text{def}} \Leftrightarrow$ отрезок $[XY]$ может быть получен из $[WZ]$ $\parallel$ переносом, при котором $W \mapsto X$ (и наоборот)

#### Введем связанные векторы

$\overline{ XY } := [~[XY\rangle~]_{\sim}$ — класс эквивалентности направленного отрезка $[XY\rangle$ (т.е. все направленные отрезки, которые равны как векторы отрезку $[XY\rangle$)

$V:=\{ \overline{ XY } ~ | ~X, Y \in E^n  \} = \{ \overline{ XY } ~ | ~Y \in E^n \} ~~\forall X \in E^n$ — векторное пространство
*(равенство работает, потому что в первом классы эквивалентности повторяются, а во втором какую бы изначальную точку не выбрали, мы все равно получим все классы)*

$\overline{ XY } = [~[XY\rangle~]_{\sim} \mapsto [XY]$ — изоморфно

#### Введем операции сложения и умножения на скаляр для связанных векторов

$\overline{ XY } + \lambda \overline{ WZ } = \overline{ XY } + \lambda \overline{ XZ^` } := [~(X, [XY] + \lambda [XZ^`])~]_{\sim}$ , где $[XZ^`\rangle \in \overline{ WZ }$

$[XY] + \lambda [XZ^`]$ — "+", "$\cdot$" в смысле операций, задающих векторные структуры


$\Rightarrow V$ — векторное пространство
$\Rightarrow(X, Y) \mapsto \overline{ XY }$ — задает аффинное пространство над $E^n$
